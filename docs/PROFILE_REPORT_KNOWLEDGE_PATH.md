## How the knowledge connects to reports

A report must follow this evidence path:

1. Resolve actual chart inputs and uncertainty, then calculate the chart facts for the correct epoch, location, frame and chart type.
2. Select the report section and its atomic requirements. Traverse the related concepts, rule IDs, dependencies, applicability and exclusions.
3. Retrieve the source propositions, original witnesses, worked examples and every linked conflict. Keep primary originals and secondary PDF evidence distinguishable.
4. Evaluate the complete context: body/point, house, sign, ruler/Delegate chain, motion, directed relationship, natal/relocated/transit/relationship role and required boundary conditions. Abstain where a source rule or chart fact is missing.
5. Produce cited, bounded prose that distinguishes calculated facts, author interpretation and user-provided life context. Do not turn a source anecdote into a user fact or a guaranteed outcome.
6. Verify source fidelity, calculation, context selection, contradiction handling, citations and the complete user workflow before approving personal use.

Research retrieval already supports examining saved concept/requirement packets. Product retrieval, personal narrative generation, life-context memory and complete interpretation workflows remain absent. Source coverage and numerical tests cannot substitute for those missing workflows.
