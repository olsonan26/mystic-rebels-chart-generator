# Frozen bounded-return standard v1

This standard precedes the implementation in `scripts/semantic_return.py`.
It does not replace the original A/B/C references or approve personal readings.

The smallest operation is an ordered partial theme: a function expressed in its
occupied Field is qualified by the Field of its calculated represented house.
Original photographed pp187 and284–285 establish transport and a worked Base
return. This is not permission to invent an occupant's assessed contribution.
The worked example validates expansion modifying action in communication; other
applications are rule applications requiring review, not independently validated
personal manifestations. Source meanings remain in the private verified core.

Acceptance criteria (evaluate separately):

1. Facts: independently recompute existing composition and function components;
   owner, placement, motion, terminology, links and contacts must match exactly.
2. Source: accept only the existing inspected finite Field meanings, and the
   existing expansion Base modifier. Unknown meanings cause withholding.
3. Traversal: derive represented houses from the trusted node, never a candidate;
   distinguish occupied Field, represented Field and sign ruler.
4. Semantics: add an ordered qualifier to the function, retaining its original
   expression area. Swapping occupied and represented roles must change the tree.
   This partial return must not imply a complete occupant/Bridge assessment.
5. Noninvention: candidate may select only existing claim IDs for the same chart
   snapshot. Extra prose, facts, relations, approval or unknown IDs cause rejection.
6. Differences: compare the unchanged four fixtures. Report withheld cases as
   withheld, not successful differentiated interpretations. Do not expand the
   finite vocabulary just to make fixtures pass.
7. Usefulness: an understandable hypothesis and a conditional adaptation are
   review artifacts. Reader usefulness and a complete personal insight require
   independent human feedback, not unit-test assertions.

Required negatives: changed house/owner/motion/contact/function, invented claim,
free prose, repeated claim, altered snapshot; missing meaning; role reversal;
claimed exclusivity/history, physical retrograde inheritance and invented contact.

The original four Qwen failures remain failures. No model is invoked. No core
release, consumer API, approval flag, source dictionary or release protection is
changed. Executable code belongs to the offline consumer review tool, not a core
audit-only path. A future core integration needs normal distribution governance.
