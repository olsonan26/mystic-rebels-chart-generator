## What the code now calculates

`relationship_context.py` creates a finite, typed condition graph from actual positions. It retains each point's direct calculated motion, separately typed physical motion, actual sign ruler, actual house Delegate, both ruled signs for Mercury/Venus, their actual houses, all evaluated occupants and condition references, and ruler cycles. Required but missing condition stages remain explicit.

The natal assessment attempts **all74 catalog entries**, including objects hidden on the wheel. Unavailable entries remain in the inventory instead of silently disappearing. For the tested2000 fixture,72 are available and SophiaMean/SophiaTrue remain unavailable. Other dates can have different availability. Inventory completeness means all catalog entries were evaluated, not that every object/method is available or all condition is interpreted. Source retrieval stays question-focused; the model cannot invent unselected body meanings from coordinates alone.

The current-sky graph is separately namespaced and dated. It includes the core and explicitly named physical bodies, declares its omitted catalog entries and has no guessed current-location houses. A sky-to-natal relation points to the fixed natal receiver packet; it never mutates the natal graph or creates reverse physical emission.

The first numeric component checks **direct conjunction coordinate reach** using explicit source values: Sun10°,Moon3°,Mars4°,Venus5° and Chiron1°. Chiron's parameter is explicitly retained as a source example. Saturn's approximately7.5° is preserved but not executed as an exact threshold. Other unapproved radii remain unknown, never a generic default or a negative result. Mathematical-point emission and unspecified point-receiver exceptions are not manufactured. Exact radius equality remains unresolved; a1e-10° comparison tolerance detects numerical equality rather than extending an orb.

This component does **not** assign complete Planet1/Planet2 roles, claim a full conjunction interpretation, qualify other aspect bands, add two radii to create direct contact, calculate Fringe strength, or infer peak dates/windows. The original chapter's aspect order and counterwording still apply. Source-faithful arithmetic is not empirical validation.
